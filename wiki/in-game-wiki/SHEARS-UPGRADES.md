## Окно

- Шапка «Улучшение предмета», справа баланс (`$ 4.55K`) и красный крестик.
- Левая карточка: иконка, название оранжевым, «Уровень N», «Стоимость N $» зелёным, синяя кнопка «Улучшить».
- Блок «Улучшения N»: строки «Ножницы a → b» и «Эффективность a → b» (новое значение зелёным).
- Блок «Требования x / 2»: «Белая шерсть 0 / N» и «Паутина 0 / N». Сколько есть — красным, пока не хватает; нужно — зелёным.
- Внизу листалка «‹ Уровень a → b ›»: можно посмотреть все будущие ступени.
