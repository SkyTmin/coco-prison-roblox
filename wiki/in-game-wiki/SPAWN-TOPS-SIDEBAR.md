# Топы на спавне и правая панель статов

22 октября 2026 года. Источник: 5 скриншотов владельца из Prison Classic: правая панель и четыре табло топов на спавне. Тексты сверены с клиентом (`wiki/client-audit/decoded/ru_RU-prison.json`). Машинно: [spawn-tops.json](spawn-tops.json).

## Правая панель (scoreboard) [владелец, клиент]

Заголовок «PRISON CLASSIC» (клиент: `prison.classic.scoreboard.title` = «Prison Classic»), синий. Строки — иконка, подпись, значение справа:

| Иконка | Подпись (клиент) | Пример | Цвет значения |
| --- | --- | --- | --- |
| зелёная стрелка вверх | Уровень | 11 | жёлтый |
| зелёный «$» | Баланс | 8,507 | зелёный, тысячи через запятую |
| серый блок | Блоки | 76.68K (42.77K) | оранжевый; в скобках серым — чистые блоки |
| — | разделитель | | |
| четыре квадрата | Фракция | Афро | серый (название фракции) |
| морда крысы | Крыс | 189 (141) | оранжевый; в скобках серым — чистые крысы |
| меч | У / С | 8 / 47 | убийства зелёным, смерти красным |

«Чистые» значения — без множителей: официальный сайт статистики Cristalix хранит отдельно `blocks` / `blocks_clean` и `rats` / `rats_clean` [сеть: top.cristalix.gg, wiki/client-audit/INDEPENDENT-GAP-RESEARCH.md].

## Табло топов на спавне [владелец, клиент]

Каменные порталы из каменного кирпича, в проёме — тёмное табло. Четыре табло (клиент: `prison.classic.board.top.*`):

| Заголовок | Колонка значения | Поле |
| --- | --- | --- |
| Топ по крысам | Крысы + иконка крысы | крысы (чистые), `cl_mobs` |
| Топ по деньгам | Деньги + зелёный «$» | баланс, 599,945.6 — до 2 знаков, тысячи через запятую |
| Топ по уровню | Уровень + зелёная точка | уровень |
| Топ по блокам | Блоки (чистые) + иконка блока | чистые блоки, `cl_blocks` |

Клиент знает ещё «Топ по смертям» (`top.deaths`), на скриншотах его нет.

Устройство табло: полоса заголовка крупным белым шрифтом; шапка «# | Игрок | <значение>»; 10 строк видно сразу, справа синяя полоса прокрутки (список длиннее). Места 1–3 — корона перед номером: 1 золотая, 2 голубая, 3 оранжевая. В ячейке игрока — донатный префикс и ранг (у нас их нет), ник цветом, через пробел кличка из кейса кличек белым («Den_Play_YT Камикадзе»). Значения зелёные.
