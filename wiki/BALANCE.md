# Архив: расчёт шахтёрского цикла v0.1

Эта модель заменена расширенным замыслом RPG в PROTOTYPE-SPEC.md. Она не учитывает дерево, землю, бои, задания и потребности. Её время до престижа не является оценкой новой игры.

Это модель активной игры, а не результат прохождения Roblox. По 1000 прогонов на маршрут с фиксированным seed.

| Маршрут | Ранг B, мин | Ранг C, мин | Престиж, мин | Престиж P10–P90, мин |
| --- | ---: | ---: | ---: | ---: |
| Без улучшений | 3.6 | 11.1 | 23.9 | 23.0–24.5 |
| С покупкой доступных кирок | 3.2 | 8.8 | 16.2 | 15.7–16.8 |
| С кирками и рюкзаками | 3.6 | 9.0 | 15.3 | 15.1–15.4 |

| Шахта | Средняя цена блока | Среднее время блока базовой киркой, с | Доход с учётом продажи, монет/с |
| --- | ---: | ---: | ---: |
| A | 1.80 | 0.844 | 1.65 |
| B | 4.55 | 0.996 | 3.65 |
| C | 13.20 | 1.412 | 7.94 |

Рюкзак продаётся целиком после заполнения. Время пути к продаже и обратно — 10 с на сумку. Покупки делаются только после продажи; их порядок указан в balance-results.json. Токены учитываются по числу блоков, но их трата и бонус добычи не моделируются.

Не учтены паузы игрока, обучение, выбор только дорогой руды, конкуренция за блоки, восстановление шахт и задержки сети. Модель добывает случайную последовательность по составу шахты. P10–P90 показывает только разброс этой последовательности. Реальные сессии могут отличаться в обе стороны.

Проверки: суммы вероятностей, известные ID руд, рост ценности шахт, ускорение кирки, неотрицательный баланс, сохранение баланса earned − spent, прохождение рангов по порядку и завершение всех прогонов.

Повторный запуск: `node simulate-balance.mjs` из этой папки. Цены и правила находятся в prototype-config.json.
