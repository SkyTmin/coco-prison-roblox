# Spider Queen — Spider Lair

Original matte voxel boss made in headless Blender: 863 cuboids, 38 joints and 12 clips [implementation]. Eight three-joint legs, separately moving abdomen/head, jaws, fangs, palps and spinnerets. The summoned huntsman uses 93 cuboids, the same 38-joint anatomy and six clips [implementation]. No commercial geometry or animation copied; no Blender GUI launched.

Review `spider_queen-motion.mp4`, `spider_queen-death.mp4`, `spider_queen-death.gif`, `spider_queen-showcase.png`, `spider_queen-death-poses.png`, `huntsman-motion.mp4` and `huntsman-showcase.png`. These show the exported Roblox curves, not an unrelated Blender animation. `reference-comparison.png` compares the original generated reference with orthographic model views. The stepped shell and bands are deliberately coarser than the concept; all eight articulated legs remain separate. Concept generated with built-in image_gen; exact prompt/mode/date in `concept-prompt.txt`.
