## Rebuild

One Blender5.2 process at a time, two threads, Studio Play stopped. For each model: `-b -t 2 -P <model>.py -- build`, then `-b <model>.blend -t 2 -P <model>.py -- export --data-only`. Primary `render_motion.py` and summons `review_summons.py -- <model>` compare/render exported curves. Primary `-- compare`, then Python `assemble_motion.py`/`assemble_summons.py` creates deliverables. `configure_runtime.py` edits only the forest_spirit decision object; regenerate configs. `integrate_runtime.py` records one-time dispatcher integration. Bounded fixture/client/live QA scripts are under `scripts/qa-forest-spirit-*.luau`.
