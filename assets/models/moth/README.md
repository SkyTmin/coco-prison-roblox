# Moth — Snowy Hand (`mole`)

Original headless Blender pale moth: 693 cuboids, 39 joints and 19 clips [implementation]. Four independently articulated wing lobes with distal bending, feathered antennae, jointed claws/legs, moving collar and three-segment abdomen. Matte cream/slate palette, no emissive eyes, lights or Neon. Generated concept used built-in image_gen; exact prompt/mode/date in `concept-prompt.txt`. Geometry simplifies the reference's tiny feather/sculpture detail while retaining the front silhouette and anatomical volumes; the generated side panel is oblique, not a consistent orthographic projection.

Review `moth-motion.mp4`, `moth-death.mp4`, `moth-death.gif`, `moth-showcase.png`, `moth-death-poses.png`, `reference-comparison.png`. Videos render the exported Roblox curves. Original `.blend`, Python model/motion and nine JSON modules are included; no commercial geometry or animation imported.
