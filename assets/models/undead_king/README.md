## Rebuild

Keep Play stopped; run one Blender5.2 process at a time with two threads. For each of `undead_king`, `undead_ghoul`, `undead_skull`, `undead_sword`: `-b -t 2 -P <name>.py -- build`, then `-b <name>.blend -t 2 -P <name>.py -- export --data-only`. Primary `render_motion.py` reviews exported curves; summons use `review_summons.py -- <name>`. Run primary `-- compare`, then Python `assemble_motion.py` and `assemble_summons.py`. `configure_runtime.py` edits only the un_king decision object; regenerate configs. `integrate_runtime.py` records guarded one-time dispatch/prop-animation integration. QA scripts are in `scripts/qa-undead-king-*.luau`.
