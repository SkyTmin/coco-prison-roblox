# 08. События и причины вернуться

Источники: `PICKAXES-DRAFT §5`, `studio/01 §5.2, §6`, `studio/04 §3.8`, `studio/05 §4.1–4.2, §5`, критика `studio/07` строки 36–39,
47, §3.2. Кадры событий — [11](11-effekty-animacii.md); бомба-таймер — [03](03-shakhta.md).

## 1. Моменты копания

### 1.1. Разгон

Копаешь без пауз → дуга разгона растёт, **4 ступени: ×1,25 / ×1,5 / ×2 / ×3** [решение PICKAXES]; с каждой ступенью громче
музыка и насыщеннее эффекты. Пауза — медленно спадает, не штраф. На HUD дуга **появляется, только когда набирается**
(07 §3.1). Разгон — временный бонус и входит в общее «×N» с потолком ([13](13-ekonomika.md)). АВТО разгон не копит.

### 1.2. Золотая жила → Лихорадка

| Параметр | Значение [решение PICKAXES / 01] |
|---|---|
| частота | случайно, раз в 3–6 мин (первая — гарантированно на ~5:30) |
| окно | 10 с: кольцо-таймер вокруг жилы, золотая стрелка у края экрана |
| удар по жиле | **Лихорадка 30 с: монеты ×5**, музыка на полную, лампы золотые |
| не успел | жила тихо гаснет за 1 с, без «грустного» звука |
| АВТО | по жиле не бьёт |

Лихорадка считается **сверх** потолка временных бонусов ([13](13-ekonomika.md)). Совпадение Лихорадки с ультой — «КОМБО!»
(игроки сами планируют сессию, иссл. п. 15).

> **Ф:** понравится — золото и монеты, понятный восторг / дофамин — неожиданное появление + окно действия + большой
> множитель / не перебор — экран не заливаем золотом, меняются лампы и края / деньги — не продаём «вызвать жилу» на запуске.

### 1.3. Не больше одного события сразу

Кроме намеренного «Лихорадка + ульта» [решение 01]. Крупные моменты T3/T4 стоят в очереди ([11](11-effekty-animacii.md)).

## 2. События сервера (запуск)

| Событие | Как устроено | Зачем |
|---|---|---|
| **Общий бур** | у сервера одна шкала; каждый сломанный блок любого игрока её двигает; **порог = база × число игроков** — соло тоже доходит | «я не один» без чата; работает и для одиночки ⚪ по умолчанию — ждёт владельца (07, строка 38) |
| **Буровой праздник** | бур на 100 % → 3 мин монеты ×2 у всех, фейерверк, баннер; награду (ключ/бустер) забирает каждый, кто внёс **≥ 5 %** шкалы | общая победа без проигравших; ≥ 5 % — чтобы AFK не получал даром [решение 05] |
| цикл бура | ≈ раз в 8–12 мин [решение 05] | проверить симуляцией |
| **Выходные** | сб–вс по UTC: **×2 ключей** | не трогает экономику монет ⚪ по умолчанию — ждёт владельца (07, строка 39) |
| **Объявления** | легендарка, рекорд глубины сервера, глобальный бустер ([09](09-khab-i-lyudi.md)) | неожиданность, честная реклама |

- Шкала бура видна **только в хабе** и баннером на 100 % — не на HUD шахты (правило «5 вещей», 07 строка 53).
- Праздник бура для ребёнка, который на сервере один, может быть непонятен («за что?») — проверить на тесте (07 §3.1).
- **Не на запуске:** Общая жила, Гонка сервера, метеорит в хабе, Землетрясение, Метеоритный дождь, Прилив, Обвал
  (обновление 1), временные миры-события (обновление 5), сезоны (обновление 7) — [15](15-zapusk-i-obnovleniya.md).

## 3. Ежедневное

**Факт про деньги** [проверено: [Creator Rewards](https://devforum.roblox.com/t/introducing-creator-rewards-earn-more-by-growing-the-community/3777628),
[документация](https://create.roblox.com/docs/production/monetization/engagement-based-payouts.md)]: с 24.07.2025 Roblox платит
создателям за игрока, если игра — одна из первых трёх за его день и он провёл в ней **не меньше 10 минут** (засчитываются
тратившие деньги на Roblox). Отсюда [решение 01]: ежедневная петля ≈ 10–15 минут; утренний повод зайти.

### 3.1. Календарь 🎁

**7 дней по кругу, пропуск ничего не отнимает** — следующая клетка просто ждёт ⚪ по умолчанию — ждёт владельца (07,
строка 36). «Шаг назад» при пропуске (`02`) и 28 клеток (`05`) отклонены: первое — всё равно наказание, второе — длинно и
давит эксклюзивом.

| День | Подарок [решение 03, правка 07] |
|---|---|
| 1 | монеты (забирается сразу, «подаренный прогресс») |
| 2 | ключ 🗝 |
| 3 | **заметный подарок**: скин молнии или гарантированная редкая кирка — **показан заранее** накануне («завтра: ⚡ синяя молния») |
| 4 | личный бустер ×2 |
| 5 | монеты |
| 6 | 3 ключа |
| 7 | большой: Сундук кирок с редкой+ ★★ |

Точный набор — ❓ (у `07` заметный день назван то «день 2», то «день 3», [17](17-ne-resheno.md)). Окно открывается само **один
раз в день** через 3 с после появления в шахте (не поверх загрузки); дальше — бейдж 🔴 на ☰ [решение 03]. Забрать можно у
Календаря в хабе **или** кнопкой с карточки «С возвращением» — ходьба не обязательна [решение 05]. Переносим `DailyService`
«Каторги».

**Сундук дня** как отдельная система — **убран**: его роль играет календарь ⚪ по умолчанию — ждёт владельца (07, строка 37).

### 3.2. Задания дня

- **3 задания** (лёгкое / среднее / сложное), иконка + число + полоска [решение 05]; все три ≈ 10–15 мин игры.
- **Привязаны к ближней цели**: «пробей Плиту», «найди 1 находку мира 2», «используй ульту 3 раза», а не «сломай 500 блоков»
  (07 §3.2).
- Одна бесплатная замена в день; сброс раз в сутки по UTC; невыполненные просто сменяются, без штрафа [решение 05].
- **Задание недели** — не на запуске, обновление 1.

### 3.3. Ночная смена (доход без игры)

Одна система под одним именем ⚪ по умолчанию — ждёт владельца (вопрос 18 из 07). («Личный бур» `05` — то же самое, имя убрано.)

- Пока игрока нет, Бригадир с роботом-буром копает: **до 8 часов**, монеты = **10 %** среднего дохода в минуту × минуты
  [решение 01].
- **Главное в ней — сундук** (шанс находки текущего мира): монеты сгорают при перерождении, вещь — нет (07 строка 47, §3.2).
- **Глубину не двигает** — миры проходятся руками.
- При входе — одна анимация 3 с «Пока тебя не было: +🪙 1.2M и сундук», кнопка «Забрать» — внутри одной карточки
  «С возвращением» вместе с календарём ([02](02-pervye-minuty.md)).

> **Ф:** понравится — вернулся, а тебе рады / дофамин — сундук при входе — неожиданность / не перебор — одна карточка,
> одна кнопка / деньги — повод быть первой игрой дня (Creator Rewards), без давления.

## 4. Уведомления Roblox

[проверено: [Experience notifications](https://create.roblox.com/docs/cloud/guides/experience-notifications)]: получают только
согласившиеся **13+**, не больше 1 в день от игры. Наше [решение 05]:

- согласие спрашиваем **во второй сессии**, после приятного момента (забрал подарок), не при первом входе;
- тексты только полезные и спокойные: «Ночная смена: сундук ждёт», «Выходные: ×2 ключей». **Никаких** «вернись, а то
  потеряешь», «друг обогнал тебя!»;
- не чаще раза в 2 дня;
- дети до 13 их **не получают** — главные причины вернуться должны быть внутри игры.

## 5. Почему ребёнок на самом деле вернётся

Подарки сами по себе не держат (07 §3.2): возвращает **недоделанное и видимое** — близкая цель на экране при выходе, «до
Плиты 40 %», силуэт следующей семьи, друг в игре, новое обновление. Расписание обновлений — [15](15-zapusk-i-obnovleniya.md).
