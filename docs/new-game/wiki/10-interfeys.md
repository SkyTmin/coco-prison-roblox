# 10. Интерфейс

Источник — `studio/03` целиком (UI-дизайнер), правки критика `studio/07` строки 5, 19, 21, 25–27, 42, 53–55, 58. Все размеры,
цвета и тайминги — [решение 03], подбираются на тесте с детьми и в эмуляторе. Старый интерфейс «Каторги» владельцу не
нравится — нужен новый, по исследованию [✅ владелец]. Правило: **иконка + цифра + одна кнопка** [✅ владелец].

## 1. Стиль

**«Яркая конфетная игрушка поверх тёмного тоннеля»:** кремово-белые пухлые панели с толстой тёмно-синей обводкой и цветной
лентой заголовка (у каждого раздела свой цвет). Тёмные полупрозрачные карточки «Каторги» убираем. ⚪ по умолчанию — ждёт
владельца (вопрос 20 из 07): **сделать 2 макета магазина кирок и выбрать по картинке**.

| Роль | Hex |
|---|---|
| панель / панель вторая | `#FFF8EC` / `#F2E6D2` |
| обводка и основной текст | `#1E2140` |
| текст в мире | белый + обводка `#1E2140` 2–3 px |
| затемнение под окном | чёрный 45 % |

**Цвет кнопки = тип действия** (одинаково везде):

| Тип | Цвет | Знак |
|---|---|---|
| купить за монеты | жёлтый `#FFC83D` | 🪙 + цена |
| купить за R$ | зелёный `#22C55E` | R$ + цена; **только** в магазине R$ и в окне Сундука кирок |
| забрать / да / в руки | синий `#3D8BFF` | ✔ |
| закрыть / нет | красный круг `#FF4D5E` | ✕ |
| нельзя | серый `#B8BDC9` | 🔒 или цена красным |
| особое (ульта, перерождение) | градиент `#A855F7` → `#EC4899` | своя иконка |

Ленты разделов: Магазин — оранжевая, Прокачка — фиолетовая, Коллекция — голубая, Ещё — бирюзовая, R$ — зелёная, Сундук
кирок — розовая. Редкости — цвет + звёзды + рамка ([04](04-kirki.md)). Иконка семьи — фон и значок в углу клетки; золотое
слияние — бегущий блик поверх.

- **Валюта:** монета-иконка + число, **без «$»** ⚪ по умолчанию — ждёт владельца (07, строка 19).
- **Сила** — ✊ (не ⚡: ⚡ только Гроза) (07, строка 54); **Прочность** — 🛡.
- **Шрифты:** цифры — Fredoka One; слова — кандидат Builder Sans ExtraBold. **Кириллицу каждого кандидата проверить в Studio
  до любых макетов** (≈ 1 час) — пока не проверено, шрифт слов не выбран ❓.
- **Иконки** — предметные (тележка, стрелка-вверх, рюкзак, сундук), через Blender-воксельный пайплайн с наклеечной обводкой
  (правило владельца 27.10).
- **Размеры** (макет под высоту 390): главная кнопка 64×64, обычная ≥ 52, промежуток ≥ 10, крестик 52 с зоной 64; текст
  ≥ 18, подписи 22–26, цифры 28–44. Один `UIScale = clamp(короткая сторона / 390, 0.85, 1.5)`, на ПК потолок 1.35.
  Ориентация — **только горизонтальная**.
- **Тайминги:** нажатие 60 мс (масштаб 0,93), отпускание 140 мс пружиной, окно 120 + 200 мс, закрытие 120 мс. Одновременно
  «зовёт» к себе не больше одного элемента.

## 2. Правила для всех экранов

1. Один экран — одно дело; одно окно за раз.
2. Иконка несёт смысл, текст подсказывает (тест: замазать текст — понятно ли?).
3. Кнопка ≤ 2 слов (ru ≤ 12 букв), описание ≤ 1 строки.
4. Закрыть тремя способами: ✕, тап по фону, «Назад»/Esc.
5. Всё отвечает за 0,1 с; отказ сервера — мягкий «бум» и покачивание, без окон-ошибок.
6. Подтверждение только для необратимого: перерождение, слияние, покупка за R$ (её подтверждает Roblox).
7. Окно ≈ 80 % экрана, игра под ним идёт (бустеры и события — без потерь).
8. Пустых экранов нет: картинка + стрелка «как получить».
9. Числа: `1.15K / 1.15M / 1.15B / 1.15T` где тесно [✅ владелец]; полное `12 540` — где важна точность.

## 3. HUD

**На экране всегда только 5 вещей** — закон ⚪ по умолчанию — ждёт владельца (07, строка 53): **монеты**, **где я**
(«Мир 4 · 63 %» + полоска, ⚪ вопрос 3 из 07), **полоска ближайшей цели**, **ульта** (+ дуга разгона, только когда набирается),
**4 кнопки меню**. Контекстно появляются и уходят: пилюля «×N» временных бонусов, АВТО (после 1-го перерождения), 🔥 (когда
перерождение доступно), стрелка к последним блокам, таймер Лихорадки, полоска Плиты. Шкала общего бура — только в хабе;
тизер следующей семьи — внутри магазина; призрака и «дружбы» нет.

**Копать — пальцем по стене** (тап, держать, вести); кнопки «Копать» нет; камера за спиной, стена всегда целиком в кадре.

### 3.4. ПК

Те же элементы на тех же местах, масштаб 1,0–1,35. Клавиши подписаны в углу кнопок только на ПК: B — Магазин, C — Прокачка,
I/Tab — Коллекция, M — Ещё, Q — Ульта, Z — АВТО, Esc — закрыть, WASD — ходить. Курсор = кирка, ЛКМ = удар, держать = бить;
колесо мыши ничего не делает. Наведение — подсказка (на телефоне — долгий тап).

### 5.1. Цифры у удара и барабан

- «+🪙» белым с обводкой, размер растёт с суммой (26 → крит 34 → ульта 44); удары в одном месте за 0,3 с — одна растущая
  цифра; раз в 0,3–0,5 с капля летит в счётчик.
- Накрутка счётчика: < 1 % — 0,3 с; ~10 % — 0,6 с; ≥ 100 % — 1,2 с; тиканье ≤ 20/с.
- **Барабан** для крупного (ульта, разлом, мегакрит): `750 блоков` → `× 🪙12` → `× 3` → `= 🪙27 000`, части по 0,25 с, у
  множителя свой звук; только если итог ≥ 20× обычного удара. **Последняя цифра — самая крупная** (07 §3.1).

## 6. Бейджи

| Бейдж | Значит | Гаснет |
|---|---|---|
| 🔴 «!» / число | можно **забрать** бесплатное (подарок, награда страницы, задание) | когда забрал |

HUD-кнопках (🔴 > 🟢 > 🟡); не мигают и не звучат; первые 5 минут — только 🟢 на магазине.
