# 05. Карточки прокачки

Источники: `PICKAXES-DRAFT §3`, `studio/02 §2.3`, `studio/03 §5.2`, `studio/04 §3.11`, `studio/06 §2.3`, критика `studio/07`
строка 35 и §3.1. Окно — в [10](10-interfeys.md), формула цены — в [13](13-ekonomika.md).

## 1. Принцип ✅ владелец

Дерево в духе Path of Exile **отклонено** [✅ владелец 09.11: «дети играть будут, всё должно быть понятно и легко»].
Вместо него — **экран карточек**:

- **Одна карточка — один эффект.** Крупная иконка, одно слово, одна строка «было → станет», большая жёлтая кнопка с ценой.
  Нажал — уровень вырос. Никаких очков, путей и сбросов [решение PICKAXES].
- **На карточке живая анимация эффекта** (петля 3 с: блок → эффект → блок) — ребёнок видит, что покупает, без чтения.
- **Карточки открываются постепенно** по глубине: новая карточка — сама маленькая награда.
- **Сборка складывается сама:** цена растёт ×1,15 за уровень, поэтому высоко качаются 2–3 любимые — «свой стиль» без
  раздумий [решение PICKAXES].
- **Кирка семьи усиливает свою карточку** (Гроза × карточка Молния): на карточке значок «⚡×2», только если такая кирка в руках
  [решение 03]. Насколько именно усиливает — ❓.

> **Ф:** понравится — «нажал — выросло», держать-и-покупать / дофамин — частые маленькие покупки + редкое превращение /
> не перебор — одна строка цифр на карточку / деньги — главный слив монет, держит idle-экономику.

## 2. Карточки запуска

**6 карточек:** Сила, Монеты, Крит, Ключи + карточки семей запуска Молния и Взрыв (07 §2.2). **Первые две на ~10:00 —
Сила и Монеты** ⚪ по умолчанию — ждёт владельца (07, строка 35): карточка «Молния» у ребёнка, у которого уже есть Гроза,
непонятна, а «цифра растёт» понятна всем.

| Карточка | Эффект за уровень [решение 02] | C₀ 🪙 [решение 02] | Открывается |
|---|---|---|---|
| ✊ **Сила** | +10 % силы | 100 | ~10:00 (мир 2) |
| 🪙 **Монеты** | +10 % монет | 150 | ~10:00 (мир 2) |
| ✨ **Крит** | +1 % шанса крита | 400 | мир 2 [решение 02] |
| 🗝 **Ключи** | +5 % шанса ключа | 1 000 | мир 3 [решение 02] |
| ⚡ **Молния** | +0,5 % шанса молнии на любой кирке | 300 | ❓ «по глубине» — точное место не назначено |
| 💥 **Взрыв** | +0,5 % шанса взрыва на любой кирке | 300 | ❓ «по глубине» — точное место не назначено |

- Размер крита: у `02` — ×5, у `04` — крит ×2–3 и отдельный «мегакрит» ×10–25 — ❓ ([17](17-ne-resheno.md)).
- Карточки Лёд (для Мороза) и Разлом в состав запуска не вошли — ❓ ([17](17-ne-resheno.md)).
- **Не на запуске:** Ульта (+25 % размера, у `02` — с первого перерождения), Скорость, Лава, Воронка, Золото, Эхо — с их
  семьями; супер-карточка **Цепная реакция** — обновление 4 ([15](15-zapusk-i-obnovleniya.md)).

**Как показывать шанс ребёнку:** не «5 % → 6 %», а **полоской** или **«1 из 20»** ⚪ по умолчанию — ждёт владельца (07 §3.1):
проценты — школьная тема 5–6 класса [мнение 07]. (Шансы **Сундука кирок** — всегда точными %: этого требует Roblox, [14](14-donat.md).)

## 3. Покупка

- Переключатель **×1 / ×10 / MAX** сверху окна; **держать кнопку = покупать подряд**, всё быстрее (0,35 → 0,1 с), каждая
  покупка — нота выше [решение 03]. Подтверждения нет (обычная покупка за монеты).
- Под карточкой — точки до превращения («▮▮▮▯▯ 25» = до превращения осталось 2 покупки) — близкая цель.
- Новая карточка: бейдж 🟡 NEW на ⬆; 🟢 «↑» — **только** когда хватает на превращение, не на каждый уровень [решение 03].
- Закрытые карточки — силуэт + мир открытия.

## 4. Превращения

На **круглых уровнях карточка меняет вид, и эффект меняется заметно** — замена «ключевым узлам» дерева, без минусов и без
выбора [решение PICKAXES]. **На запуске — уровни 10 и 25**; 50 и 100 — обновление 4 (07 §2.2–2.3).

- Пример из черновика: «Молния 25: теперь ветвится», «Взрыв 50: цепные взрывы». Что именно меняет каждое превращение у
  каждой из 6 карточек — ❓ ([17](17-ne-resheno.md)).
- Рамка: бронза → серебро (10) → золото (25) → радужная (поздние) [решение 04].
- Кадры: карточка подпрыгивает, переворачивается 2 оборота, лучи цвета эффекта, новая рамка и анимация, подпись ≤ 3 слов,
  стингер; кнопка «Попробовать» — следующий удар гарантированно показывает новую форму ([11](11-effekty-animacii.md)).

## 5. При перерождении

**Уровни карточек сгорают, открытие — нет** [решение 01 + 02]: карточки открыты сразу, уровни = 0, докупаются за минуты —
это часть «быстрого повторного пути» ([06](06-pererozhdenie.md)).

## 6. Псевдослучайный шанс (PRD)

Шанс срабатывания стартует ниже заявленного и растёт после каждого промаха, сбрасывается после срабатывания: в среднем
тот же %, но без долгих «засух» и серий (25 % обычным броском может не сработать 20 ударов подряд) [практика, иссл.
п. 14, [Liquipedia](https://liquipedia.net/dota2/Random_Distribution)].

- Считает **только сервер**, состояние PRD хранится на сервере по каждому эффекту [решение 06].
- Тот же приём — у редких находок ([07](07-nakhodki-i-kollekcii.md)); ключи на тысячах блоков — «накопитель»
  (`шанс × блоки`, пока ≥ 1 — выдать ключ), без серий невезения и без выгоды от перезахода [решение 06].

## 7. Бюджет каскада

Защита от «один удар ломает сервер и экономику» [решение 06]:

| Лимит на один удар | Значение |
|---|---|
| поколений срабатываний | ≤ 3 |
| клеток в видимом окне | ≤ 400 |
| «прогонов» глубже окна (разлом, ульта) | ≤ 8 |

- На запуске фишка срабатывает от удара (молния, взрыв), но «эффект вызывает эффект» включает только Цепная реакция
  (обновление 4). Лимиты действуют уже на запуске: на них держатся ульты и молния вглубь.
- Каждое следующее поколение звучит на тон выше; если на экране слишком много — мелкие срабатывания показываем только
  вспышкой и цифрой; **цифры и звук не урезаются никогда** [решение 04].
- Каскад воспроизводим тестом с фиксированным зерном ([16](16-tekhnika-i-plan-rabot.md)).
