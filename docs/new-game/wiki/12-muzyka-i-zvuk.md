# 12. Музыка и звук

Источник — `studio/04 §5`, `PICKAXES-DRAFT §7`, `studio/03 §3.9`, правки критика `studio/07` строка 60, вопрос 22, риск 5.
Музыка важна [✅ владелец, BRIEF]. Цифры — [решение 04].

## 1. Принципы

1. **Один темп во всей игре — 120 BPM** (такт 2 с, доля 0,5 с): совпадает с эхом Резонанса и облегчает привязку событий к долям.
2. **У каждого мира свой лад; все «музыкальные» звуки — в ладу текущего мира:** ноты молнии, барабан цифр, «дзынь» крита,
   покупки подряд. Записываем заготовку на одной ноте и транспонируем `PlaybackSpeed = 2^(полутоны/12)`. Пентатоника — любые
   ноты подряд и вместе звучат приятно; молния играет арпеджио вверх, каскад — мелодия, а не шум.
3. **Стингеры квантуются к доле:** ждут ближайшую долю, если до неё < 150 мс; иначе играют сразу. Картинка не ждёт никогда.
4. **Громкость:** музыка на −14 дБ ниже эффектов; на T3+ музыка «приседает» на 6 дБ.
5. **Потолок голосов:** ≤ 16 эффектов одновременно; однотипные — не чаще раза в 60–120 мс.

## 2. Слои по Разгону

**На запуске — 2 слоя (база + полный) + Лихорадка**; 4 слоя — только после теста синхронности стемов на слабом телефоне
⚪ по умолчанию — ждёт владельца (вопрос 22 из 07). Музыка — самая дорогая и самая непроверенная часть (07, риск 5).

| Слой (цель — 4) | Когда звучит | Что в нём | На запуске |
|---|---|---|---|
| L0 атмосфера | всегда | пэд, гул мира | **база** = L0 + L1 |
| L1 ритм | разгон ×1,25 | лёгкие ударные | ↑ |
| L2 бас и гармония | разгон ×1,5 | бас, аккорды | **полный** = всё вместе с ×1,5 [предложение редактора, ❓] |
| L3 мелодия | разгон ×2 | ведущий инструмент мира | ↑ |
| L4 пик | разгон ×3 | контрмелодия + тарелки (можно фильтром/октавой L3) | ↑ |
| **Лихорадка** | событие | отдельный трек того же темпа: удвоенные ударные, золотые колокольчики; одна тема в 3 тональностях под лады миров | да |

- Слой включается на ближайшей сильной доле за 0,5 с, гаснет медленно (4 с) — пауза в копании не обрывает музыку.
- Реализация: все стемы крутятся одновременно, меняется только громкость (`Sound.Volume` или новый Audio API: `AudioPlayer` →
  `AudioFader` → `AudioDeviceOutput` [devforum: [Audio API exits beta](https://devforum.roblox.com/t/roblox-audio-api-exits-beta-enhanced-sound-controls-now-available/3153454)]);
  раз в 4 с подравниваем `TimePosition` при сдвиге > 40 мс.
- **Тест до записи всей музыки:** 4 стема × 32 с на слабом телефоне — на этапе 2 работ ([16](16-tekhnika-i-plan-rabot.md)).
  Запасной план: каждый слой — отдельная законченная версия трека, переход кроссфейдом на границе такта.

(аккорд), 10 слоёв (2 доли), 100 слоёв (1 такт), ульта (1 такт), жила (3 ноты вверх), новая кирка (2 такта), легендарка
(4 такта), новый мир (2 такта), перерождение (4 такта, хор), объявление (1 такт), превращение (2 такта), ульта готова (тихий
аккорд).

## 4. Звуки

Источник: **А** — атлас VoxeLibre «Каторги» (уже загружен, лицензии CC BY-SA / CC BY / CC0 → **титры в игре обязательны**,
`assets/thirdparty/voxelibre/ATTRIBUTION.md`); **С** — синтез нашим скриптом по формулам прототипа (наше); **З** — заказ;
**Н** — нотный сэмпл, транспонируется.

| Группа | Звуки | Источник |
|---|---|---|
| Удары | «тук» и разлом по материалу (камень, гравий, металл, лёд, стекло, корни), 3–4 варианта, ±5 % высоты; отскок кирки | А + С |
| Монеты, криты | тихий «дзынь» (5 нот), крит, мегакрит («вдох», «бум», аккорд), барабан цифр («тик», «тынь» множителя, «дзынь» итога) | С + Н |
| Стена | гул подъезда, «клац» слоя, свист разгона, реактивный гул, хор «а-а», удар остановки малый/большой/огромный, тик счётчика | С + З |
| Гроза | нота прыжка (колокольчик + треск 30 мс), гром малый/большой/раскат, гул шаровой, ветер ульты | Н + С |
| Разлом / Динамит / Мороз | хруст вглубь; тик, «БАХ», дым; иней, раскол стекла по нотам | С + А + Н |
| Жила, Лихорадка, бомба | «блинг-блинг», монеты, тик-так | Н + С |
| Сундук кирок | 3 толчка на нотах, открытие ×4 редкости | Н + С + З |
| Интерфейс | тап «поп» (±3 %), окно «вжух», покупка — каждая следующая на ноту выше (до 8, сброс за 1 с), «нельзя» мягкий «бумп», забрал — перезвон; **бейджи молчат** | С |
| Мир, персонаж | капли, ветер тоннеля, далёкий гром соседа; шаги по материалу | А + С |

Итого ≈ 70–90 коротких звуков → **один-два атласа** (как `scripts/build-sounds.mjs`: один файл, сегменты по `TimePosition`);
стемы — отдельными файлами. Формулы прототипа (`tone`, `noise`) переносим в node-скрипт рядом с `build-sounds.mjs` — всё
синтезированное принадлежит владельцу. Отдельный канал громкости «Интерфейс» ([10](10-interfeys.md)).

## 5. Где брать музыку легально

| Вариант | Можно? | Годится для |
|---|---|---|
| **Заказать композитору** с передачей прав / лицензией на Roblox | да | темы миров со стемами — основной путь; цену не знаем |
| **Сочинить самим** (DAW, синтез; Claude/Codex может набросать MIDI) | да | бесплатно, права наши; качество проверять |
| **Лицензированная Creator Store** (APM, Monstercat, DistroKid…) | только внутри Roblox | **только хаб/меню**: нельзя скачать → нельзя резать на стемы и подгонять темп/лад |
| Открытые лицензии CC0 / CC BY | да, с титрами | отдельные звуки; CC BY-SA и NC для музыки избегать |
| ИИ-генерация | осторожно | не рекомендуем для основных тем без юриста |
| Чужая музыка из игр и песни | **нет** | нарушение прав, Roblox удаляет |

Кто делает музыку — ❓ ([17](17-ne-resheno.md), ⚪ вопрос 22 из 07).

**Лимит загрузок аудио** [по выдаче поиска: [Audio assets](https://create.roblox.com/docs/audio/assets)]: файл < 20 МБ и < 7 мин;
**100 бесплатных загрузок за 30 дней без верификации, 2 000 — с верификацией ID**. В CLAUDE.md «Каторги» записано «10 в месяц»
(цифра 2022 года) — [проверить] владельцу в Creator Hub. Потребность ≈ 50–60 загрузок (атласы + 10 миров × стемы + Лихорадка +
хаб). Звук по умолчанию приватный — давать доступ experience при загрузке.
