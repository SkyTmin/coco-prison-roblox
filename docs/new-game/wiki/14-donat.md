# 14. Донат

Источники: `studio/02 §3–4, §5.2, §6`, `studio/03 §5.6, §5.12`, `studio/04 §3.9`, `studio/05 §4.4, §6`, критика `studio/07` строки
20–29 и §5, вопросы 9–13. Окна — [10](10-interfeys.md). Правила Roblox для детей и платных случайных предметов — обязательны
[✅ владелец, BRIEF: «все исходы и точные шансы ДО покупки; без обмана; аудитория — дети»].

## 1. Принцип

За R$ — **быстрее и красивее**, но никогда «только за деньги». Всё, что даёт силу, достаётся и бесплатно; эксклюзив за R$ —
только внешний вид [решение 02]. Самый сильный честный товар — **вид молнии**: её «вау» — главная причина играть (07 §2.2).

Почему не давим: платят немногие (¾ детей вообще не тратят [офиц. опрос GameTrack 2023, `02 §3.2`]), а Roblox платит через
**Creator Rewards** за удержание и возвращение игроков ([08](08-sobytiya-i-vozvrat.md)) — каждая минута удержания уже деньги
(07 §5.3).

## 2. Состав запуска

⚪ по умолчанию — ждёт владельца (вопрос 10 из 07).

| Товар | Тип | Цена [решение 02] | Что даёт |
|---|---|---|---|
| **×2 Монеты** | геймпасс | 199 R$ | все монеты ×2 навсегда (постоянный множитель, [13](13-ekonomika.md)) |
| **VIP** | геймпасс | 299 R$ | **только косметика:** золотая рамка ника, значок, цвет следа. Без VIP-уголка в хабе и без «+1 ежедневного сундука» ⚪ 07 §5.2 |
| **Вид молнии и следов кирки** | косметика | 149–399 R$ (у `02` — диапазон «скинов эффектов») | цвет и форма разряда, след, аура в хабе — **на запуске, а не «позже»** (07 §5.3); точный список и цены ❓ |
| **Бустер личный** | расходник | 39 R$ / 30 мин | ×2 монет тебе |
| **Бустер серверный** | расходник | 99 R$ / 30 мин | ×2 всем 5 на сервере, ник покупателя на баннере — «щедрая» покупка |
| **Бустер глобальный** | расходник | 249 R$ / 30 мин | ×2 на всех серверах, ник на баннере; **не чаще одного глобального в 10 мин** (очередь) |
| **Сундук кирок** | платный случайный | 79 R$ за **одно** открытие | §3 |
| **Набор новичка** | разово на аккаунт | 99 R$ | скин кирки, 3 ключа, 2 личных бустера, рамка «Первопроходец»; лежит в магазине, **не всплывает** |

- **Бустеры: области личный / серверный / глобальный**, «серверный» встаёт на место «фракционного» (фракций в новой игре нет
  ни в одном разделе); правило 2 + 2 + 2 = ×6 сохраняется 🔶 предлагаем изменить решение владельца «локальные / фракционные /
  глобальные» ⚪ по умолчанию — ждёт владельца (вопрос 13 из 07).
- **Бустеры за монеты не продаются** — только за R$ и бесплатно из наград (календарь, задания, бур) ⚪ по умолчанию — ждёт
  владельца (07, строка 23). Время идёт по часам сервера и в офлайне; очередь одного вида — друг за другом (как
  `Boosters.luau` «Каторги»).
- **Цены — чуть ниже пакетов Robux** (80 / 400 / 800 / 1 700 / 4 500 R$): 29, 39, 79, 99, 149, 199, 249, 299, 399 … — ребёнок с
  пакетом 80 покупает товар за 79 без «хвоста» [решение 02; опыт «Каторги», владелец 28.10]. Цену в интерфейсе берём у Roblox
  (`GetProductInfoAsync`) — региональные цены [офиц.].
- Ориентир: 100 R$ покупки → ~70 R$ разработчику → ~$0,27 по DevEx [слабо, `02 §3.3`].

> **Ф:** понравится — каждый товар объясняется одной картинкой / дофамин — ×2 сразу видно в «+🪙», вид молнии — своё «вау» /
> не перебор — 2 пасса, 3 бустера, 1 сундук, 1 набор, косметика / деньги — классика жанра без pay-to-win.

## 3. Сундук кирок: шансы и гарантия

**Один платный сундук на запуске** ⚪ по умолчанию — ждёт владельца (07, строка 25) (три кейса из макета `03` и шансы
60/25/10/4,5/0,5 — отклонены).

| Редкость | Шанс [решение 02] | Гарантия |
|---|---|---|
| Обычная ★ | 60 % | — |
| Редкая ★★ | 30 % | — |
| Эпическая ★★★ | 8,5 % | не позже 10-го открытия без эпической и выше |
| Легендарная ★★★★ | 1,5 % | не позже 60-го открытия без легендарной |

Внутри редкости все кирки семей запуска — с равными шансами (можно показать одной строкой — разрешено [офиц.]).

**Правила для всех случайных наград** [решение 02, на основе правил Roblox]:

1. **Шансы видны у всех сундуков, даже бесплатных** (за ключ): каждый исход и %, до нажатия, сумма 100 %.
2. **Гарантия (pity) — полоской на экране:** «до ★★★: 7», «до ★★★★: 41». Считаются **все** открытия (бесплатные тоже);
   счётчик не сгорает при перерождении.
3. **Анимация честная:** результат решает сервер **до** анимации; **сундук, а не лента** ⚪ по умолчанию — ждёт владельца
   (07, строка 26); никакого «почти выпало». 1,5–3 с, пропуск.
4. **Платный — только по одному:** без «ещё раз», без ×5/×10, без пакетов 3/10 ⚪ по умолчанию — ждёт владельца (вопрос 11 из 07).
5. **Лимит — 10 платных открытий в сутки на аккаунт** (у `02` было 50 ≈ 3 950 R$ в день — для ребёнка не ограничение)
   ⚪ по умолчанию — ждёт владельца (вопрос 11 из 07).
6. `PolicyService:ArePaidRandomItemsRestricted()` → кнопка «Купить сундук» скрыта; бесплатный за ключи остаётся. Замена
   на прямую покупку конкретной кирки (`02 §4.1`) — ❓ ([17](17-ne-resheno.md)).
7. Всё купленное за R$ и выпавшее из платных сундуков — **привязано** (не продаётся и не передаётся) [решение 05].
8. Дубликаты полезны: 3 одинаковые → золотая ([04](04-kirki.md)).
9. Сервер пишет журнал каждого платного открытия (кто, когда, что, по каким %) — для поддержки и проверки частот.

Бесплатная дорога к редким без удачи: выбор эпической каждые 5 перерождений, выбор легендарной за Плиту мира 8 ([04](04-kirki.md)).

## 5. Список «никогда» — тёмные паттерны

Основа: отчёт Сиднейского университета 2026 (обман в 14 из 15 топовых игр Roblox) и Eiger и др. 2025 (71,9 % из 82 миров)
[наука/пресса, ссылки — `02`]. [решение 02, правки 07]:

1. Нет фальшивых скидок, зачёркнутой навсегда «старой цены», таймеров «только 10 минут».
2. Нет всплывающих окон покупки во время копания, после неудачи, на экране перерождения. **Никаких всплывающих предложений
   вообще** — набор новичка лежит в магазине ⚪ по умолчанию — ждёт владельца (вопрос 12 из 07).
3. Нет «серии, которая сгорит»: календарь при пропуске ничего не отнимает ([08](08-sobytiya-i-vozvrat.md)).
4. Нет промежуточной валюты за R$.
5. Нет «почти выпало».
6. Цена в R$ на кнопке совпадает с окном Roblox.
7. Описание = то, что товар делает: перед покупкой — живая анимация эффекта.
8. Нет «подарка», который надо оплатить; нет давления через друзей («купи, а то сосед обгонит»).
9. Первые 10 минут — никаких предложений о покупке.
10. Не больше 10 платных сундуков в сутки, только по одному.
11. Бейджи и мигание никогда не зовут платить; зелёная кнопка R$ — только в магазине R$ и у Сундука кирок ([10](10-interfeys.md)).

## 6. Граница pay-to-win

Платящий всем набором запуска обгоняет бесплатного активного игрока **примерно на 2–4 перерождения** — заметно, но
догоняемо [решение 02, проверить симуляцией]. Топы «глубже всех» и «перерождения» общие; топы, где деньги не помогают
(коллекция, рекорд без бустеров), — позже.

## 7. Метрики и аналитика доната

Кастомные события `AnalyticsService` [решение 02]: `pickaxe_buy`, `card_level`, `world_reach`, `rebirth`,
`case_open(free/paid, rarity)`, `shop_open`, `purchase_prompt`, `purchase_done`, `booster_start(scope)`. Цены не трогать до
D1/D7; тест цен (Price Optimization) — после ~1 000 DAU. Цели метрик — [15](15-zapusk-i-obnovleniya.md).
