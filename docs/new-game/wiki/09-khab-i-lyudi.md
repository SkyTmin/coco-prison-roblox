# 09. Хаб, топы, люди, безопасность детей

Источники: `studio/05 §2–4, §6`, `studio/04 §2.4, §3.14`, `studio/01 §2.7`, `studio/03 §4.5, §5.8`, `studio/06 §2.5`, критика
`studio/07` строки 31–33, 40–44, §6. 5 человек на сервере, у каждого своя шахта, в чужую доступа нет [✅ владелец].

## 1. Хаб

**Площадь у подножия горы под открытым небом; пять ворот в скале ведут в тоннели игроков** ⚪ по умолчанию — ждёт владельца
(вопрос 23 из 07). Сочетает контраст неба (`04`) и короткий путь пешком (`05`).

- **Зачем хаб, если всё есть кнопками:** всё частое (магазин, карточки, Сундук кирок, бустеры, задания, настройки) — кнопкой
  из шахты; в хабе — то, что ради людей и показухи [решение 05].
- **Дорога:** из шахты развернулся — 6 с пешком — ты на площади; **или** кнопка «Хаб» / «В шахту» — мгновенно с короткой
  вспышкой [решение 05]. Ходьба — выбор, не обязанность.
- **Когда показываем:** ворота в хаб открываются после **первой Плиты** (~8–10 мин) как награда «новое место»; тропа к
  подарку появляется, но никто не ведёт силой и камеру не забирает (⚪ вопрос 23 из 07; [02](02-pervye-minuty.md)).
- **Размер:** ≈ 70 × 70 studs; центр → любая постройка ≈ 2–3 с, ворота → дальний угол ≈ 6–8 с (WalkSpeed 16 по умолчанию)
  [решение 05].
- Хаб и устья держим постоянными/Atomic при StreamingEnabled; стену каждой шахты рисует только её хозяин [решение 05/06].

   |        [#2 серебро]        [#1 ЗОЛОТО — статуя]        [#3 бронза]          |
   |                         статуи топ-3 НЕДЕЛИ по глубине                      |
   |                                                                           |
   |  ВОРОТА 1 ===\                                              /=== ВОРОТА 5  |
   |  ник, ⛏1.15K  \                                            /  ник, ⛏ 820   |
   |  витрина кирки \           .----------------.             /  витрина кирки |
   |                 \          |  ОБЩИЙ БУР     |            /                 |
   |                  +---------|  шкала сервера |-----------+                  |
   |                 /          '----------------'            \                 |
   |                /         (алтарь 🔥 — украшение)           \                |
   |  ВОРОТА 2 ===/                                              \=== ВОРОТА 4  |
   |  витрина             [КАЛЕНДАРЬ 🎁]                              витрина    |
   |                                                                           |

   +---------------------------------------------------------------------------+
                                    ЮГ
   Скамейки, фонари, декор. Без лабиринтов и второго этажа. Аукциона, машины сундуков,
   метеорита, табло «Сервер сегодня» на запуске нет.

### 1.2. Ворота

- 5 ворот = 5 шахт. Над воротами: аватар-иконка хозяина, ник, глубина «⛏ 1.15K», **витрина** лучшей кирки (крутится на
  пьедестале, светится цветом редкости) [решение 05].
- **Чужие ворота закрыты прозрачным полем**: смотреть можно, войти нельзя; удары по чужой шахте сервер отвергает
  [✅ владелец; решение 06].
- Свободные ворота (игроков < 5) — тёмные, с иконкой «ждём шахтёра».

## 2. Хвастовство

| Что | Как на запуске | Пометка |
|---|---|---|
| **Цифра над ником** | **одна** строка: иконка + число «1.15K / 1.15M»; по умолчанию — **глубина** рекорда; игрок может выбрать монеты/блоки | ⚪ по умолчанию — ждёт владельца (07, строка 42); формат ✅ владелец |
| **Значок ранга** у ника | по Кубкам ([06](06-pererozhdenie.md)) | [решение 01] |
| **Витрина** над воротами | лучшая кирка | [решение 05] |
| **Статуи** | топ-3 **недели** по глубине: фигура = аватар игрока + его кирка, табличка «ник · 1.15M», раз в 10 мин | ⚪ по умолчанию — ждёт владельца (вопрос 24 из 07) |
| **Соседи видны** | ульта соседа — **вспышка над его воротами** (видна из всего хаба) + **далёкий гром у себя** в шахте | ⚪ по умолчанию — ждёт владельца (07, строка 43) |
| **Объявления** | плашка сверху ([§4](#4-объявления)) | [решение 03/04] |

**Не на запуске:** упрощённая стена соседа (6 слоёв), окно-балкон в чужую шахту, ауры по перерождениям, титулы из
достижений, «праздник соседа» с «искрой удачи» (07 строки 24, 43; §2.2).

## 3. Топы

Топ-100 + твоё место внизу [✅ владелец]. ⚪ по умолчанию — ждёт владельца (вопрос 24 из 07):

- **Доски:** глубина, монеты (заработано всего), блоки, перерождения.
- **Два режима: неделя (главный на экране — у новичка есть шанс) и всё время.**
- **Место:** точно до 1 000; дальше «1000+ · до топа ещё X» [решение 06 v1]. Корзины-гистограммы `05` для точной оценки —
  потом (07, строка 40).
- Своя строка **всегда видна** внизу с ближней целью «↑ до 500-го: 340K» (до ближайшего круглого места) [решение 03].
- Топ-3 — медали и аватары; те же доски стоят в хабе. Переносим `LeaderboardService` + `TopBoards.luau` (`TOP_N` 20 → 100,
  1 000 — кэш на сервер раз в 5 мин) [решение 05/06].
- OrderedDataStore хранит только целые → в топ «по монетам» пишем `floor(log10(монеты) × 10^6)` [решение 06].
- Нет метода «место ключа» в OrderedDataStore [форум: [1](https://devforum.roblox.com/t/getting-the-position-of-a-key-in-an-ordereddatastore/13890),
  [2](https://devforum.roblox.com/t/how-to-find-a-players-rank-in-an-entire-ordereddatastore/1136342)] — поэтому «1000+».

## 4. Объявления

Только по-настоящему редкое: легендарная кирка, рекорд глубины сервера, глобальный бустер, Ядро [решение 03/04/05].
Плашка сверху 4 с: аватар + ник + иконка предмета, слов минимум (перевод не ломается). Не чаще 1 в 4 с, очередь 3, похожие
склеиваются («Kirill и ещё 2 получили легендарки»). Своё — с конфетти у себя. Тап по плашке — «Поздравить» (👏 летит к
игроку) [решение 04]. На все серверы — только глобальный бустер (с ником).

## 5. Что связывает пятерых без чата

На запуске (07 §2.2): **объявления о легендарках**, **вспышка ульты соседа над воротами**, **Общий бур** (порог от числа
игроков, [08](08-sobytiya-i-vozvrat.md)), **реакции-смайлы**, **серверный бустер** (купил один — радуются все, [14](14-donat.md)).

- **Чат** — стандартный Roblox, своего не пишем. С 2026 Roblox требует проверку возраста для чата, у детей **до 9 лет чат по
  умолчанию выключен** [проверено: [пресс-релиз 07.01.2026](https://www.businesswire.com/news/home/20260107986568/en/Roblox-Requires-Users-Worldwide-to-Age-Check-to-Access-Chat)]
  ⇒ вся социальность работает без слов.
- **Круг реакций** (кнопка-смайлик): 6 своих иконок 👍 🔥 ⚡ 😮 🎉 💎, только позитивные, над головой и над воротами 3 с,
  перезарядка 3 с [решение 05]. Иконки — Blender-пайплайн.
- **Убраны** (07 строки 24, 53): «хлопок» +10 %, бонус «Дружба» +10–20 %, «искра удачи», призрак-соперник, Гонка сервера.
- **Одиночке не скучно:** бур с порогом от числа игроков, недельная доска и «до топа ещё X». Ботов, притворяющихся
  игроками, не делаем [решение 05]. Запуск будет с почти пустыми серверами — всё социальное обязано работать соло (07 §6.2).

## 6. Тело игрока

**Аватар Roblox R15**, а не блочное тело «Каторги» ⚪ по умолчанию — ждёт владельца (вопрос 19 из 07): дети дорожат своим
видом, статуи и витрины с их аватарами — мотиватор. Нужна защита камеры от огромных аватаров ([03](03-shakhta.md)).

## 7. Безопасность и детская аудитория

### 7.1. Правила Roblox [проверено: [Paid random items](https://create.roblox.com/docs/production/monetization/paid-random-items), [PolicyService](https://create.roblox.com/docs/reference/engine/classes/PolicyService)]

| Правило | Что делаем |
|---|---|
| платные случайные предметы: все исходы и точные % до покупки | окно Сундука кирок всегда показывает шансы и гарантию ([14](14-donat.md)) |
| `ArePaidRandomItemsRestricted = true` | прячем покупку Сундука кирок за R$; бесплатные (за ключи) остаются |
| `IsPaidItemTradingAllowed = false` | всё купленное за R$ и выпавшее из платных сундуков — **«привязано»** у всех |
| свой текст, который видят другие, — только через фильтр Roblox | **свободного ввода текста нет вообще** — только иконки и готовые фразы |
| уведомления — 13+, opt-in, ≤ 1/день | [08](08-sobytiya-i-vozvrat.md) |

### 7.2. Наши запреты [решение 05]

- награда за лайк / избранное / подписку — нет;
- таймеры-страшилки за R$, «потеряешь серию», ложная редкость, «почти выпало» — нет ([14](14-donat.md));
- азарт между игроками (ставки, лотереи), обмен на R$ / вне игры, подарки предметами между детьми — нет;
- **прямого обмена 1-на-1 нет**; аукцион — не на запуске ⚪ по умолчанию — ждёт владельца (вопрос 15 из 07);
- негативные реакции, «смех над слабым», топ «худших» — нет;
- сбор личных данных, ссылки наружу, «добавь в друзья ради награды» — нет;
- боты под видом игроков — нет.

### 7.3. Защита от травли

Объявления — только ник и иконка; игрок может скрыть чужие реакции (настройки); стандартная блокировка Roblox.
Приглашения друзей и реферальная система «Каторги» (`ReferralService`) в состав запуска критика не вошли — ❓ ([17](17-ne-resheno.md)).
