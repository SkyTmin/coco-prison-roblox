## 0. Коротко: 12 главных решений

1. **Светлые «конфетные» окна вместо тёмных карточек.** Тоннель тёмный → кремово-белые панели с толстой тёмно-синей обводкой и
   цветной «лентой» заголовка видны сразу и выглядят по-детски. Тёмные полупрозрачные карточки старой игры — убираем.
2. **Иконка + цифра + одна кнопка.** У каждой карточки/строки ровно одно главное действие. Подписи ≤ 2 слов (≤ 12 букв
   по-русски), смысл несёт иконка и цвет, а не текст.
3. **Копаем пальцем прямо по стене.** Тап = удар по блоку, держишь = бьёт без остановки, ведёшь пальцем = бьёт то, что под пальцем.
   Отдельной кнопки «копать» нет. Справа — одна большая кнопка **УЛЬТА** (заряжается кольцом).
4. **На экране всегда только 5 вещей:** деньги, «где я» (пласт · слой), полоска ближайшей цели, кнопка ульты с полоской
   разгона, 4 кнопки меню слева. Остальное появляется по делу и исчезает.
5. **4 кнопки меню, не 12:** 🛒 Магазин · ⬆ Прокачка · 🎒 Коллекция · ☰ Ещё. Внутри — крупные вкладки-иконки. Одно окно за раз.
6. **Цвет денег различимый:** покупка за монеты — жёлтая кнопка с монетой; за Robux — всегда зелёная с значком R$ и только
   в одном месте (магазин Robux); «Забрать» — синяя. Ребёнок не перепутает игровые деньги с настоящими.
7. **Редкость = цвет + число звёзд + форма рамки** (не только цвет — для дальтоников).
8. **Пять уровней «шума»:** цифры в мире → тосты → баннер → «вау»-экран → объявление сервера. Для каждого уровня — лимит
   частоты и очередь; «вау»-экран можно пропустить тапом и он не чаще раза в ~2 мин (кроме первого раза).
9. **Три вида бейджей, а не один красный:** 🔴 «!» — есть что ЗАБРАТЬ; 🟢 «↑» — хватает денег улучшить; 🟡 «NEW» — новое,
   ещё не видел. Бейджи на донат — никогда.
10. **Шрифт:** цифры — мультяшный Fredoka One (цифры и K/M/$ есть в любом шрифте); слова — шрифт с кириллицей
    (кандидат Builder Sans ExtraBold) — **проверить кириллицу в Studio до старта**.
11. **Настройки «спокойнее»:** меньше тряски, без вспышек, качество эффектов, громкость музыки/звуков/интерфейса, язык. Вспышки
    в любом режиме не чаще 3 раз в секунду.
12. **Без давления:** нет таймеров-страхов на покупки, нет «потеряешь серию», нет мигающей кнопки доната, нет «почти выпало».

## 2. Правила интерфейса (для всех экранов)

1. **Один экран — одно дело.** Окно отвечает на один вопрос («что купить?», «что улучшить?»). Одно окно за раз; новое окно
   заменяет старое.
2. **Иконка несёт смысл, текст подсказывает.** Ребёнок, который не прочитал ни слова, всё равно должен понять экран по иконкам,
   цветам кнопок и анимации. Тест: замазать весь текст на скриншоте — понятно ли, что делать?
3. **Подписи:** кнопка ≤ 2 слова, ru ≤ 12 букв [решение]; описание ≤ 1 строки. Никаких абзацев. Длинные пояснения — только
   в «?» (по нажатию), и то картинкой.
4. **Размеры (в точках макета высотой 390, см. 3.7):** главная кнопка 64×64; обычная ≥ 52; промежуток между целями ≥ 10;
   крестик закрытия 52 с зоной касания 64. Текст ≥ 18 на телефоне, основные подписи 22–26, цифры 28–44.
5. **Закрыть можно тремя способами:** большой красный ✕, тап по затемнённому фону, кнопка «Назад»/Esc. Никаких ловушек.
6. **Цвет кнопки = тип действия** (одинаково на всех экранах, см. 3.3).
7. **Всё отвечает за 0,1 с:** нажатие — сразу сжатие + звук, даже если сервер ещё думает. Если сервер отказал — мягкий «бум»
   и короткое покачивание, без красных окон с текстом.
8. **Подтверждение только для необратимого и дорогого:** перерождение, слияние кирок, продажа на аукционе, покупка за Robux
   (её подтверждает сам Roblox). Обычные покупки за монеты — без подтверждения, сразу (важно для «купить ×10 быстро»).
9. **Окно не закрывает стену целиком надолго.** Стена — сердце игры; окна занимают ~80 % экрана, и игра под ними продолжается
   (руда не копается сама, но бустеры и события идут — без потерь).
10. **Пустых экранов нет:** у каждого пустого состояния — картинка + стрелка «как получить».
11. **Числа:** формат владельца `1.15K / 1.15M / 1.15B / 1.15T` везде, где тесно (ник, HUD, цены); полное число с пробелами
    `12 540` — где важна точность (окно покупки) [владелец, BRIEF].
12. **Локализация:** каждая строка во всех 4 языках (правило репозитория). Макет рассчитан на самую длинную версию; на тесте —
    «псевдо-язык» (+40 % длины) [практика, И9].

## 3. Стиль

### 3.1 Идея

«**Яркая конфетная игрушка поверх тёмного тоннеля**». Мир — тёмный тоннель с цветной рудой и светом ламп; интерфейс — светлые,
пухлые, скруглённые «наклейки» с толстой обводкой. Контраст «тёмный мир — светлый UI» делает каждую кнопку заметной без
лишнего размера. Внутри окон — цветная лента-заголовок (свой цвет у каждого раздела: ребёнок узнаёт раздел по цвету).

**Фильтр.** Понравится: яркое и пухлое — привычный детям вид симуляторов [наблюдение, М1]. Дофамин: косвенно — UI не спорит с
эффектами по яркости. Не перебор: светлая панель + 1 цвет ленты + кнопки трёх цветов — мало оттенков. Деньги: нейтрально.

### 3.2 Палитра (hex, [решение])

**Основа**

| Роль | Цвет | Hex |
|---|---|---|
| Панель окна | кремово-белый | `#FFF8EC` |
| Панель вторая (ячейки, строки) | светло-бежевый | `#F2E6D2` |
| Обводка всего (панели, кнопки, иконки) | тёмно-синий «чернильный» | `#1E2140` |
| Основной текст на светлом | тёмно-синий | `#1E2140` |
| Текст на цветном/в мире | белый + обводка `#1E2140` 2–3 px | `#FFFFFF` |
| Затемнение под окном | чёрный 45 % | `#000000` α 0.45 |

**Кнопки (цвет = тип действия)**

| Тип | Цвет | Hex (верх / «губа» снизу) | Знак |
|---|---|---|---|
| Купить за монеты | жёлтый | `#FFC83D` / `#D99A12` | монета 🪙 + цена |
| Купить за Robux | зелёный | `#22C55E` / `#15803D` | значок R$ + цена; **только** в разделе Robux и в окне кейса |
| Забрать / Да / Взять в руки | синий | `#3D8BFF` / `#1F5FCC` | ✔ или подарок |
| Закрыть / Нет | красный круг | `#FF4D5E` / `#C42638` | ✕ |
| Нельзя (не хватает, закрыто) | серый | `#B8BDC9` / `#8A90A0` | 🔒 или цена красными цифрами `#E5333F` |
| Особое (ульта, перерождение) | фиолетово-розовый градиент | `#A855F7` → `#EC4899` | своя иконка |

**Ленты разделов:** Магазин — оранжевая `#FF8A1F`; Прокачка — фиолетовая `#8B5CF6`; Коллекция — голубая `#2BB3F3`;
Ещё — бирюзовая `#14B8A6`; Робуксы — зелёная `#22C55E`; Кейсы — розовая `#F43F8E`.

**Валюты и HUD:** деньги — золото `#FFD23F` с обводкой; ключи — латунь `#E8B04B`; глубина — голубой лёд `#7DD3FC`;
разгон — от жёлтого `#FDE047` к красному `#F97316` по ступеням.

### 3.3 Редкости

Редкость читается **тремя признаками сразу**: цвет рамки, число звёзд, форма/украшение рамки [И7].

| Редкость | Цвет | Hex | Звёзды | Рамка | Звук открытия |
|---|---|---|---|---|---|
| Обычная | серо-голубой | `#A9B4C2` | ★ | простой скруглённый квадрат | короткий «тук» |
| Редкая | синий | `#3FA9FF` | ★★ | + уголки | «дзинь» |
| Эпическая | фиолетовый | `#A35BFF` | ★★★ | + огранка, лёгкое свечение | аккорд вверх |
| Легендарная | оранжево-золотой | `#FF9F1C` | ★★★★ | + лучи за рамкой, медленный блик | фанфара (стингер в тональности) |
| Гибрид / мифическая | радужный перелив | градиент | ✦ (знак вместо звёзд) | + вращающиеся лучи | большой стингер |

**Уровни слияния** (из PICKAXES-DRAFT: 3 одинаковые → золотая, 3 золотые → радужная) рисуются **поверх** редкости, а не новым
цветом: золотая — золотой блик пробегает по иконке раз в 2 с; радужная — радужная кайма. Так не путается «легендарная» и «золотая».

**Семья кирки** (Гроза, Разлом, Динамит …) — цвет фона внутри иконки и маленький значок семьи в углу (⚡ 🟧 💣 ❄ 🔥 🌀 💰 🎵).
Итого на одной клетке: фон = семья, рамка + звёзды = редкость, блик = слияние. Больше ничего на клетке нет.

**Фильтр.** Понравится: блеск и звёзды — понятно без слов «эта круче». Дофамин: звук открытия растёт с редкостью — ожидание
перед редким. Не перебор: три признака, все визуальные. Деньги: видна разница редких — желание собрать.

### 3.7 Масштаб под экраны

- Макет рисуем в точках для **высоты 390** (типичный телефон в горизонтали; iPhone 12–15 = 390 pt) [решение].
- Один `UIScale` на весь UI: `scale = clamp(короткая сторона / 390, 0.85, 1.5)`; на ПК потолок 1.35, чтобы окна не были
  гигантскими. На маленьких телефонах (высота 320–360) — 0.85 и левая колонка сжимается до 3 кнопок + «Ещё».
- Ориентация: **только горизонтальная** (`ScreenOrientation = LandscapeSensor`) — стена 5×3 широкая, и вертикальный режим
  удвоил бы работу. [решение]
- HUD — `ScreenInsets = CoreUISafeInsets` [И5]; окна и затемнение — `None` (на весь экран), содержимое окна — внутри безопасной зоны.

### 3.8 Анимации

Все тайминги — [решение] по мотивам [М4]; режим «меньше движения» (раздел 8) заменяет масштабы и прыжки на простые проявления.

| Что | Как | Время |
|---|---|---|
| Нажатие кнопки | масштаб 1 → 0,93, губа сжимается | 60 мс, ease-out |
| Отпускание | 0,93 → 1,06 → 1 (пружина) | 140 мс, Back |
| Окно появляется | фон 0 → 45 % затемнения; окно 0,85 → 1,04 → 1 + прозрачность 1 → 0 | 120 + 200 мс |
| Окно закрывается | 1 → 0,92 + исчезает | 120 мс (закрытие всегда быстрее открытия) |
| Ячейки в окне | появляются «волной» сверху-слева, задержка 20 мс на ячейку, максимум 12 ячеек анимируются, остальные сразу | ≤ 300 мс всего |
| «Можно купить» (призыв) | одна кнопка на экране слегка покачивается (±4°) раз в 4 с | 400 мс |
| Получение предмета | иконка вылетает из точки события по дуге к кнопке раздела, кнопка «глотает» её (сжатие 1,15) | 450 мс |
| Монеты в HUD | «+$» летит к счётчику денег, счётчик подпрыгивает 1 → 1,12 → 1 | 300 мс |
| Накрутка числа | см. 6.6 | 0,3–1,2 с |
| Вкладки | переключение без «полёта» страниц — только плавное появление | 120 мс |

Правило: **одновременно «зовёт» к себе не больше одного элемента** на экране (одно покачивание, одно свечение). Иначе экран
«кричит» отовсюду и ничего не слышно.

### 3.9 Звуки интерфейса

Отдельный канал громкости «Интерфейс». Все звуки короткие (≤ 0,4 с), мягкие, **в тональности музыки** (пентатоника, как удары и
молнии в PICKAXES-DRAFT §7): покупки подряд звучат как мелодия, а не как пулемёт.

| Событие | Звук | Правило |
|---|---|---|
| Тап по кнопке | мягкий «поп» | высота чуть случайная (±3 %), чтобы не надоедал |
| Окно открылось / закрылось | «вжух» вверх / вниз | тише клика |
| Купил за монеты | «дзынь» монетки | при покупке подряд каждая следующая на ноту выше (до 8 ступеней), пауза 1 с — сброс |
| Не хватает / нельзя | мягкий «бумп» (не резкий «ошибка») | + покачивание кнопки ±6 px |
| Забрал награду | искристый перезвон | |
| Накрутка цифр | тиканье | не чаще 20 тиков/с, высота растёт к концу |
| Множитель «×3» | отдельный «удар» | (Д12: у множителя свой звук) |
| Редкость при открытии | 5 звуков по редкостям (3.3) | |
| Бейдж появился | без звука | бейджи молчат — иначе спам |

Лицензия: в новой игре звуки — свои или с открытой лицензией с атрибуцией (как атлас VoxeLibre в старой игре); пайплайн

## 4. HUD — что на экране во время копания

### 4.1 Главный вопрос: как копать на телефоне

**Решение: копать пальцем прямо по стене. Большой кнопки «Копать» нет.**

- Тап по блоку → удар по этому блоку (клиент шлёт намерение «ударил по клетке x, y», сервер решает — PLAN п. 17).
- **Держишь палец** на стене → кирка бьёт без остановки в своём темпе (это и есть «авто» для активной игры).
- **Ведёшь пальцем** по стене → бьёт блок под пальцем. Детям нравится «тереть» стену; скорость та же, что у тапов (сервер
  ограничивает темп), — нет выгоды бешено стучать, автокликер бессмыслен.
- Стена 5×3 на экране → блок ~70–90 точек — большая цель, промахов почти нет [И2].
- Зависимость от других кусков: камера должна смотреть на стену и **не вращаться от пальца по стене** (иначе тап по стене =
  поворот камеры). Предлагаем: камера закреплена за спиной/над плечом, поворот — двумя пальцами или кнопкой 🎥 (как в старой игре).
  Перемещение по площадке — стандартный стик слева.

**Авто-копание (без пальца):** предлагаем кнопку-переключатель «АВТО» рядом с ультой, бесплатно, открывается после обучения:
персонаж сам бьёт ближайшую руду, но **медленнее (×0,6)**, без Разгона и без кликов по Золотой жиле. Так можно
положить телефон, но играть руками выгоднее. **Открытый вопрос владельцу** — бесплатно ли (наше мнение: да; платное «авто»
дети воспринимают как «плати, чтобы не играть», а игровой пропуск лучше сделать на скорость авто, см. 5.12).

**Фильтр.** Понравится: прямое касание = самое понятное («жму на камень — ломается»). Дофамин: каждый тап — удар, звук, «+$».
Не перебор: ноль новых кнопок. Деньги: оставляет место для пропуска «Авто ×2» без отнятия базового.

```
     └─ ☰ ЕЩЁ (бирюзовый) ───────── плитки: [🎁 Подарки] [🏆 Топы] [🔨 Аукцион] [🔥 Перерождение] [⚙ Настройки]

```

Почему 4, а не 10 кнопок: каждый лишний значок на HUD — шум, а на телефоне — место, где не стена. Частые дела (купить кирку,
улучшить карточку) — в 1 тап; редкие (аукцион, топы, настройки) — в 2 тапа.

**Фильтр.** Понравится: меньше кнопок — меньше растерянности. Дофамин: нейтрально. Не перебор: да, главный выигрыш. Деньги:
магазин Robux — вкладка Магазина (1–2 тапа), без отдельной мигающей кнопки; честно и не мешает.

### 5.1 Магазин кирок (🛒 → ⛏ Кирки)

**Назначение:** купить следующую кирку (стартовая линейка: 1 блок → 1×2 → 1×3 → крест → 3×3) и обычные кирки семей по мере
открытия пластов (PICKAXES §1). Главное — «коплю на следующую» (Д7).

```
╔═════════[ 🛒 МАГАЗИН · КИРКИ ]══════════════════════════════════════╗(✕)
║ 🪙 1.15M                                                           ║
║  ┌────────┐   ┌────────────┐   ┌────────┐   ┌────────┐   ┌───────┐ ║
║  │ ⛏ ✔   │   │  ⛏ (крутится)│  │ ⛏      │   │ ▒▒▒    │   │ ▒▒▒   │ ║
║  │ В РУКАХ│   │ ★  СЛЕДУЮЩАЯ │  │ ★      │   │ 🔒 ??? │   │ 🔒??? │ ║
║  │ ■      │   │ ■■■ ← форма  │  │ ▪■▪    │   │ Пласт 3│   │Пласт 5│ ║
║  │        │   │ ⚡+40% 💨+20%│  │ ■■■    │   │        │   │       │ ║
║  │        │   │[🪙 2.0K]    │  │[🪙 8.5K]│  │        │   │       │ ║
║  └────────┘   └────────────┘   └────────┘   └────────┘   └───────┘ ║
║   ◀ листать пальцем ▶                                              ║
╚═══════════════════════════════════════════════════════════════════╝
```

- **Карточка кирки:** 3D-иконка (медленно крутится у выбранной), звёзды редкости, **рисунок формы удара** клетками (■, ■■■,
  крест, 3×3) — ребёнок видит «эта ломает три», не читая; 2 цифры со значками (⚡ сила, 💨 скорость) в сравнении с текущей
  («+40 %» зелёным); жёлтая кнопка с ценой.
- Карусель сама открывается **на следующей доступной** кирке; она крупнее соседей.
- Хватает денег → кнопка яркая и покачивается (единственный «зов» на экране). Не хватает → серая, цена красная + маленькая
  полоска «сколько накоплено» прямо на кнопке.
- Купил → кирка вылетает в руку (персонаж в мире её поднимает), окно закрывается само через 0,6 с, «вау»-экран новой кирки
  (6.4) — только для семейных/редких, для стартовой линейки — короткий баннер.
- Будущие кирки — силуэт + замок + иконка пласта, на котором откроются (любопытство «что дальше», BRIEF «пустота»).
- **Жесты:** свайп — листать; тап по карточке — подробнее (живая мини-анимация удара этой кирки на маленькой стенке 5×3).
- **Пусто:** не бывает (всегда есть хотя бы следующая).
- **Без чтения:** форма удара рисунком, «+%» зелёным, цвет кнопки = «можно купить».

**Фильтр.** Понравится: витрина «что дальше» + крутящаяся модель. Дофамин: близкая цель и ожидание (полоска на кнопке).
Не перебор: одна кнопка на карточку. Деньги: главная «утечка» монет (idle-экономика, Д9).

### 5.2 Карточки прокачки (⬆ Прокачка)

**Назначение:** тратить монеты на шансы фишек (PICKAXES §3): Молния, Взрыв, Лёд, Лава, Воронка, Золото, Эхо, Крит, Ключи, Сила,
Скорость, Ульта; позже — супер-карточка «Цепная реакция».

```
╔═════════[ ⬆ ПРОКАЧКА ]═══════════════════════════════[ ×1 | ×10 | MAX ]═╗(✕)
║ 🪙 1.15M                                                                ║
║ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐        ║
║ │ ⚡ (живая │ │ 💥       │ │ ❄        │ │ ▒▒▒▒     │ │ ▒▒▒▒     │        ║
║ │ анимация)│ │          │ │          │ │  🔒       │ │  🔒       │        ║
║ │ МОЛНИЯ 12│ │ ВЗРЫВ 4  │ │ ЛЁД 1    │ │ Пласт 3  │ │ Пласт 4  │        ║
║ │ 5% → 6%  │ │ 2% → 3%  │ │ 1% → 2%  │ │          │ │          │        ║
║ │ ▮▮▮▯▯ 25 │ │ ▮▮▯▯▯ 10 │ │ ▮▯▯▯▯ 10 │ │          │ │          │        ║
║ │[🪙 1.2K]↑│ │[🪙 300] ↑│ │[🪙 50]  ↑│ │          │ │          │        ║
║ └──────────┘ └──────────┘ └──────────┘ └──────────┘ └──────────┘        ║
║   ◀ ▶  (2 ряда на ПК, 1 ряд + листание на телефоне)                    ║
╚════════════════════════════════════════════════════════════════════════╝
```

- **Карточка:** живая петля эффекта (3 с: блок → эффект → блок) — «вижу, что покупаю» [PICKAXES §3]; название 1 слово; уровень;
  одна строка «5 % → 6 %» (было → станет, стрелка зелёная); **точки до превращения** («▮▮▮▯▯ 25» = до вида «Молния 25»
  осталось 2 покупки — близкая цель, Д7); жёлтая кнопка цены.
- **Купить ×1 / ×10 / MAX** — переключатель сверху (дети любят MAX). **Держать кнопку = покупать подряд**, всё быстрее
  (0,35 с → 0,1 с), каждая покупка — нота выше (3.9). Это самое «вкусное» действие экрана.
- Кирка семьи усиливает свою карточку → на карточке значок семьи «⚡×2» (только если такая кирка в руках).
- **Превращение** (10/25/50/100): карточка вылетает в центр, переворачивается, новая анимация, подпись «ТЕПЕРЬ ВЕТВИТСЯ!» —
  баннер-уровень (6.4).
- Новая карточка открылась (раз в несколько минут) — на HUD «⬆» бейдж 🟡 NEW, в окне карточка с блеском-рамкой, пока не тронул.
- Закрытые — силуэт + пласт открытия.
- **Пусто:** первые ~10 минут вкладка закрыта: кнопка ⬆ на HUD появляется **в момент открытия** первых карточек (PICKAXES §6:
  ~10:00) с анимацией «вылета» — меньше кнопок в начале, само появление = награда.
- **Без чтения:** живая анимация, «→» зелёная, точки прогресса.

**Фильтр.** Понравится: «нажал — выросло», держать-и-покупать. Дофамин: частые маленькие покупки + редкое превращение.
Не перебор: одна строка цифр на карточку; сборка «складывается сама» ценой ×1,15. Деньги: основной слив монет, держит
idle-экономику.

### 5.3 Коллекция: кирки (🎒 → ⛏) и слияние (🎒 → ✨)

**Назначение:** все свои кирки, выбрать «в руки», увидеть, чего не хватает (альбом), слить 3 одинаковые.

```
╔═════════[ 🎒 КОЛЛЕКЦИЯ · КИРКИ ]════════════════════[ 23 / 130 ▓▓░░ ]═╗(✕)
║          ★      ★★      ★★★     ★★★★                                 ║
║ ⚡ Гроза [⛏ ✔] [⛏ ×2]  [▒ ???]  [▒ ???]                              ║
║ 🟧 Разлом[⛏]   [▒ ???] [▒ ???]  [▒ ???]                              ║
║ 💣 Динам.[⛏ ×3✨][⛏]   [▒ ???]  [▒ ???]   ← «×3✨» = можно слить       ║
║ ❄ Мороз [▒ ???][▒ ???] [▒ ???]  [▒ ???]                              ║
║  …  (листать вниз)                                                   ║
║ ✦ Гибриды [▒ ?] [▒ ?] [▒ ?] [▒ ?]                                    ║
╚══════════════════════════════════════════════════════════════════════╝
```

- Таблица «семья × редкость» — сразу видно, что пусто (силуэты «???», PICKAXES §1) → желание закрыть дыры.
- Счётчик «23/130» с полоской в заголовке.
- Тап по кирке → **карточка кирки**: большая 3D-модель (вращать пальцем), живая анимация удара и ульты, 2–3 значка-цифры,
  кнопки «✔ В РУКИ» (синяя) и «✨ СЛИТЬ» (фиолетовая, если ≥ 3 копий).
- **Слияние:** три иконки летят в центр, вспышка (одна, медленная), выходит золотая/радужная. Подтверждение: «3 ⛏ → 1 ✨⛏»
  картинкой + удержание кнопки 1 с (необратимо).
- Неизвестная кирка (силуэт) → тап показывает «где взять»: значок кейса / пласта / «слей 2 легендарки» для гибридов (иконками).
- **Пусто:** у новичка 1 кирка → остальное силуэты, стрелка к магазину. Нормально и даже полезно.

**Фильтр.** Понравится: коллекционирование — одно из самых любимых у детей. Дофамин: дыры в альбоме = ожидание. Не перебор:
одна таблица; гибриды отдельной строкой внизу. Деньги: видимые «???» редких двигают к кейсам (честно, с шансами).

### 5.5 Бустеры (🛒 → 🧪 и тап по пилюле бустеров на HUD)

```
╔═════════[ 🧪 БУСТЕРЫ ]═══════════════════════════════════════════════╗(✕)
║  СЕЙЧАС:      🧑 ×2   +   👥 ×2   +   🌍 ×2   =   🪙 ×6  ⏱ 12:30      ║
║             (мой)      (фракция)    (сервер)                         ║
║ ───────────────────────────────────────────────────────────────────── ║
║  У МЕНЯ:  [🧪 ×2 · 10 мин  (3)] [🧪 Удача · 5 мин (1)]  → [ВЫПИТЬ]    ║
║  КУПИТЬ:  [🧪 ×2 · 30 мин  🪙 50K]   [🧪 ×2 · 1 ч  R$ 49]             ║
╚══════════════════════════════════════════════════════════════════════╝
```

- Главная строка — **сложение картинкой**: «×2 + ×2 + ×2 = ×6» [владелец: складываются]. Ребёнку видно, откуда ×6.
- «Выпить» — синяя (своё, бесплатно); покупка за монеты — жёлтая, за Robux — зелёная.
- Глобальный бустер другого игрока: тост «🌍 ВАСЯ дал всем ×2!» + мини-конфетти; это «связь» (Д8).
- Код старой игры (`Boosters.luau`, `BoosterService`, `BoosterWindow`) переносится, меняется только вид.

### 5.6 Кейсы и окно шансов (🛒 → 📦, и сундук в лобби)

**Назначение:** открыть кейс ключами из шахты или купить. По правилам Roblox **все исходы и точные шансы видны ДО покупки**
(Д5, [офиц.](https://create.roblox.com/docs/production/monetization/paid-random-items)).

```
╔═════════[ 📦 КЕЙСЫ ]═════════════════════════════════════════════════╗(✕)
║ [📦 Шахтёрский] [📦 Грозовой] [📦 Легендарный]  ← карусель кейсов     ║
║ ┌──────────────────────────────────────────────────────────────────┐ ║
║ │  ВНУТРИ (шансы ВСЕГДА видны, не за кнопкой):                    │ ║
║ │  [⛏★ 60%] [⛏★ 25%] [⛏★★ 10%] [⛏★★★ 4.5%] [⛏★★★★ 0.5%]        │ ║
║ │  с бустом удачи: шансы пересчитаны здесь же (жёлтая метка 🍀)    │ ║
║ │  ГАРАНТИЯ: ★★★★ не позже чем через ▓▓▓▓▓▓░░░░ 23 открытия        │ ║
║ └──────────────────────────────────────────────────────────────────┘ ║
║     [🗝 ×1  ОТКРЫТЬ]   (синяя — ключ есть)    [R$ 99  КУПИТЬ И ОТКРЫТЬ]║
╚══════════════════════════════════════════════════════════════════════╝
```

- Шансы — **крупно, на самих предметах**, в процентах с точностью до сотых, без «?» и без сворачивания.
- Счётчик гарантии (pity) — полоской: честное «скоро точно».
- **Открытие:** лента прокрутки 2,5–3 с с замедлением (ожидание — часть награды, Д3) → остановка → «вау» по редкости (6.4).
  **Без фальшивого «почти выпало»** (правило Д1): лента останавливается на выпавшем предмете честно, мы не подкладываем
  легендарку «рядом» специально; соседние клетки берутся случайно по тем же шансам.
- Пропуск анимации: после 1-го открытия появляется «⏩» (быстро — 0,6 с). Открыть ×5 / ×10 — сетка карточек переворачивается
  волной, лучшая — последней.
- Нет ключа → кнопка серая, под ней «🗝 ключи — в шахте» иконкой (стрелка к стене).
- **Без чтения:** проценты рядом с картинками, полоска гарантии, цвет кнопки.

**Фильтр.** Понравится: прокрутка и вспышка редкости — любимый момент жанра. Дофамин: ожидание + неожиданность. Не перебор:
одна карусель, две кнопки. Деньги: главный платный продукт — и при этом полностью честный по правилам Roblox.

- **Купить:** сетка, тап → карточка предмета + «КУПИТЬ 🪙» (подтверждение — удержание 1 с, потому что дорого и необратимо).

- Поиск 🔍 — только для ПК/старших; дети пользуются фильтрами-иконками.

### 6.6 «+$» и накрутка чисел

- **«+$» у точки удара** (PLAN п. 10): белые цифры с обводкой, размер растёт с суммой (обычный удар 26 → крит 34 → ульта 44);
  цвет по событию: обычный — золото, крит — оранжевый с «!», золотой блок — блестящее золото, Лихорадка — радужный край.
- **Склейка:** удары в одном месте за 0,3 с → одна цифра, которая растёт на месте («+120 … +360 … +600») — меньше шума и
  приятнее, чем 10 цифр.
- **Полёт к счётчику:** раз в 0,3–0,5 с капля «$» летит к деньгам в HUD (не каждая цифра!).
- **Накрутка** (Д12): деньги в HUD катятся к новому значению, длительность по размеру прибавки: < 1 % — 0,3 с; ~10 % — 0,6 с;
  ≥ 100 % — 1,2 с. Тиканье ≤ 20/с.
- **«Барабан» для крупных событий** (ульта, разлом, каскад, PICKAXES §5): плашка по центру внизу:
  `750 блоков` → `× 12 $` → `× 3` → `= 27 000 $` — каждая часть выезжает по очереди (0,25 с), множитель — со своим звуком,
  итог накручивается и **улетает в деньги**. Показывается только если итог ≥ 20× обычного удара (иначе это обычная цифра).
- Числа везде в формате владельца K/M/B/T; в «барабане» — полностью, если влезает (точность радует).

### 6.7 Бюджет «шума» в минуту (ориентир для теста)

Обычная минута копания: L0 — сколько угодно (со склейкой), L1 — 2–6, L2 — 0–1, L3 — 0 (чаще 1 раз в 5–15 мин), L4 — 0–2.

**Фильтр (весь раздел).** Понравится: «вау» в нужные моменты. Дофамин: три частоты наград (Д6) видны на экране — L0 каждые
секунды, L1/L2 минуты, L3/L4 — десятки минут. Не перебор: лимиты и склейка. Деньги: L4 о легендарках — социальная реклама
кейсов без давления.

## 7. Бейджи «есть что сделать»

### 7.1 Три вида

| Бейдж | Вид | Значит | Когда гаснет |
|---|---|---|---|
| 🔴 **!** (или число) | красный круг, белый «!», для наград — число | можно **ЗАБРАТЬ** бесплатное: ежедневка, проданный лот, награда альбома, задание | когда забрал |
| 🟢 **↑** | зелёная стрелка | хватает денег на **следующую кирку** или на **превращение** карточки / выгодно перерождение | когда купил ИЛИ открыл экран и закрыл без покупки (до следующего «нового» повода) |
| 🟡 **NEW** | жёлтая плашка «NEW»/звёздочка | появилось **новое**: новая карточка, новая кирка в магазине, новая находка | когда увидел (элемент был на экране ≥ 1 с) |

### 7.2 Правила против спама [решение, М5]

1. **Только по реальному поводу из сервера** — счётчик бейджа считается из тех же данных, что и экран (иначе «врёт», М5).
2. **Никогда:** на доносе, на кейсах за Robux, на «купи ещё бустер», на «можно улучшить карточку №7 на 1 уровень».
   🟢 для карточек — только для **превращения** (10/25/50/100), не для каждого уровня, иначе горит вечно.
3. **Бейдж на HUD-кнопке = «внутри есть бейдж»**, ведёт к месту: открыл 🛒 — вкладка с бейджем подсвечена, карточка с бейджем
   прокручена в видимую часть.
4. **Одновременно бейджи максимум на 2 HUD-кнопках.** Приоритет: 🔴 > 🟢 > 🟡. Остальные ждут.
5. **«Увидел» гасит 🟡 и 🟢**, даже если не купил; 🟢 вернётся только при **новом** поводе (следующая кирка стала по карману).
6. **Бейджи не мигают и не звучат.** Один раз «выпрыгивают» (1 → 1,2 → 1, 200 мс) при появлении — и всё.
7. **Первые 5 минут — только 🟢 на магазине** (главный урок «копи на кирку»), остальные системы ещё не показаны.

**Фильтр.** Понравится: подсказка «куда нажать» без чтения. Дофамин: 🔴 = бесплатная награда ждёт. Не перебор: ≤ 2 кнопки,
3 смысла. Деньги: честно — бейджи никогда не зовут платить.

**Фильтр.** Понравится: родителям и чувствительным детям — да. Дофамин: не снижает основное (звук и hit-stop остаются).
Не перебор: 1 экран, всё иконками. Деньги: удержание тех, кто ушёл бы из-за вспышек/тормозов.

## 9. Тексты и 4 языка

- **Лимиты длины** (по самой длинной версии из 4 языков): кнопка ≤ 12 знаков; заголовок окна ≤ 16; тост ≤ 24; баннер ≤ 28 [решение].
  Короткие строки при переводе растут сильнее всего (+100–200 % для строк до 10 знаков, И9) — поэтому смысл держит иконка,
  а кнопка **растягивается по тексту** (AutomaticSize X) в пределах 1,6× базовой ширины, дальше текст ужимается до минимума
  18 (`TextScaled` + `UITextSizeConstraint`).
- **Короткие формы** вместо длинных слов: «КУПИТЬ / BUY / COMPRAR / ACHETER» — все ≤ 8; «В РУКИ / EQUIP / EQUIPAR / ÉQUIPER».
- Числа и знаки (K, M, $, ×, %) — одинаковые во всех языках; формат K/M — единый [владелец].
- Псевдо-язык для теста: русская строка + 40 % «ёёё» — все окна должны выдержать (И9).
- Код строк: `src/shared/Strings/` (init + Part-модули, ru по умолчанию) переносится; правило репозитория — каждая строка во
  всех 4 языках.

## 10. Первые минуты — как интерфейс учит без текста

(Сценарий первых 5 минут — кусок 9; здесь только инструменты интерфейса.)

- **Рука-указатель:** анимированная рука «тапает» по нужному месту (по блоку, по кнопке) — до первого действия игрока, потом
  исчезает. Повтор, если 8 с бездействия.
- **Появление по одному:** на старте HUD = деньги + цель + стена. Кнопка 🛒 вылетает, когда хватает на 2-ю кирку (~0:30–1:00,
  PICKAXES §6), ульта — к первой зарядке (~2:00), ⬆ — к ~10:00, 🎒 — после первого кейса (~4:00), ☰ — после первого
  пласта или при первой ежедневке. Каждое появление — маленькая награда и урок «эта кнопка — для этого».
- **Подсказки-комиксы** (5.13) вместо текстов.
- **Цель всегда на экране** (полоска 4.2) — ребёнок без слов понимает «коплю вот на это».

**Фильтр.** Понравится: ничего читать не надо. Дофамин: каждая новая кнопка — событие. Не перебор: в начале 3 элемента.
Деньги: удержание первой сессии — основа всего (Д10).

## 11. Техника интерфейса (для Codex/Claude)

- **Слои ScreenGui** (DisplayOrder): 1 HUD (`CoreUISafeInsets`) · 2 цифры/тосты · 3 окна · 4 баннеры · 5 «вау» · 6 системное.
- **Один UIScale** на слой, формула 3.7; макет в Offset под высоту 390, без смешивания Scale/Offset внутри компонентов.
- **Пул объектов** для «+$», тостов, ячеек сеток (топ-100, коллекция) — без создания/удаления каждый раз (слабые телефоны).
- **Виртуальная прокрутка** для топ-100 и аукциона: рисуем только видимые строки.
- **Не больше ~30 одновременных твинов UI**; накрутка чисел — в одном RenderStepped, не твинами на каждую цифру.
- **Ui-кит заново:** новый `Ui.luau` (кнопка-конфета, панель, вкладки, ячейка, бейдж, тост) — один модуль, все окна строятся
  из него; старый тёмный кит не переносим. Переносим логику и сервисы: Strings, HudLayout/HudDefaults (редактор), Boosters,
  Auction, Leaderboards/TopBoards, Daily, Sfx/Audio, PlayerPreferences.
- **Кнопка ульты** якорится к кнопке прыжка при старте и при смене размера экрана (И4); если прыжок отключён — к правому
  нижнему углу безопасной зоны.
- **Сервер решает всё:** UI только показывает и шлёт намерения (купить карточку X, открыть кейс Y); цены и шансы приходят с
  сервера (шансы в окне кейса — из того же конфига, что и выдача).
- Проверка: эмулятор телефона Studio (iPhone SE 667×375 — самый тесный, iPhone 14 844×390, планшет 1024×768), ПК 1920×1080;
  атрибут `ForceMobile` для тач-режима (как в старой игре).

## 13. Открытые вопросы к владельцу

1. **Светлые окна** (кремовые с синей обводкой) — нравится направление? Или хочется ярко-цветных панелей (синих/фиолетовых)?
   Предлагаем сделать 2 макета одного окна (магазин кирок) и выбрать по картинке.
2. **Авто-копание:** бесплатно (×0,6, без Разгона), платно или совсем нет?
3. **Камера:** закрепить за спиной (тап по стене = удар, поворот двумя пальцами) — согласны? Иначе тапы конфликтуют с поворотом.
4. **Прыжок** оставить (дети любят прыгать) или убрать (на площадке не нужен, освобождает угол под ульту)?
5. **Шрифт:** проверка кириллицы в Studio — разрешите сделать до любых макетов (≈ 1 час).
6. **Одно предложение-набор новичка** за Robux в естественной паузе — допустимо или вообще никаких всплывающих предложений?
7. **Недельный топ** рядом с «за всё время» — нужен (шанс новичкам) или только «всё время»?
8. **Ежедневка:** без сброса серии при пропуске — согласны?
9. **Порядок появления кнопок** в первые 10 минут (раздел 10) — устраивает, или все 4 кнопки сразу?
10. **Звуки интерфейса** — свои (заказать/сгенерировать) или из библиотеки с открытой лицензией?
