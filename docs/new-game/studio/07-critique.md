## 0. Вердикт коротко

1. **Шесть разделов — это шесть разных игр.** Они согласны в главном (стена, молния, автопродажа, честные шансы), но
   расходятся в каркасе: сколько миров, как устроено перерождение, сколько валют, где появляется игрок, есть ли питомцы.
   Пока нет одного «канона», Codex писать нечего: любое ТЗ будет противоречить половине документов.
2. **Перебор огромный.** Геймдизайн (01 §7) перечисляет 41 систему, из них «на запуске» — около 30. Технический план
   (06 §5) — 37–51 «день Codex» — покрывает примерно половину из них (нет питомцев, хаба, музея, большинства событий,
   заданий, Ночной смены) [мнение]. Реально выпустить можно треть.
3. **Ребёнок утонет в словах:** пласт, слой, ульта, разгон, жила, лихорадка, карточка, превращение, экспедиция, звёзды,
   сила, твёрдость, Плита-страж — 13 новых слов за первые 30 минут. Бриф требует «иконка + цифра + одна кнопка».
4. **Сильные стороны, которые надо сохранить при любой резке:** копать пальцем по стене (03 §4.1), молния по очереди с
   нотами (04 §3.5), езда стены по логарифму (04 §3.4), первая молния до 5-й минуты (05 §1.3), Плита-страж как
   «босс без монстра» (01 §2.4), честные шансы + гарантия без премиум-валюты (02 §1, §4), лестница интенсивности
   T0–T4 и очередь «вау» (04 §3.0, 03 §6.1), «квоты» шахты (06 §1.4).

## 2. Перебор: что выкинуть, что отложить

### 2.1. Почему резать обязательно

- Codex пишет по ТЗ, Claude проверяет. Опыт «Каторги» в этом репозитории: одна система (обучение, боссы, аукцион)
  доходила до приёмки владельцем через многие сессии QA [мнение по CLAUDE.md].
- 06 оценивает свои 10 этапов в 37–51 «день Codex». В этих этапах нет: хаба, питомцев, находок кроме «коллекций»,
  событий кроме жилы, заданий, Ночной смены, музея, испытаний, гонки сервера. Если добавить всё, что 01 и 05 пометили
  «на запуске», это, по моей оценке, ×1,7–2 к объёму [мнение] — то есть 3–4 месяца до запуска вместо ~2.
- Каждая лишняя система — ещё слово, ещё кнопка, ещё бейдж для ребёнка (фильтр 3 брифа).

   против агрессивного доната.
